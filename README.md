# learn strategic thinking with phoebe

Eight 45-minute sessions teaching 50+ thinking models the way strategists actually use them - as stacks applied to one real problem, not a souvenir collection of templates. Every framework (MECE to Lean Canvas, Five Forces to pirate metrics, Rumelt's kernel to OKRs) is applied live to one running case, and by Session 8 the room has assembled a complete board-ready strategy. Built for managers through C-level: each page is a 45-minute live session plus self-study depth, with apply-along exercises, quizzes, and sources cited to their origins.

Live site: https://phoebefu6.github.io/learn-strategic-thinking-with-phoebe/

## The sessions

| # | Session | Category | Level |
|---|---------|----------|-------|
| 1 | Think like a strategist | Foundation (MECE, issue trees, pyramid, 80/20) | 🟢 |
| 2 | Decide with confidence | Decision-making | 🟢 |
| 3 | Find the real problem | Troubleshooting & investigation | 🟡 |
| 4 | Read the battlefield | External strategy & planning | 🟡 |
| 5 | Design the business | Business analysis & models | 🟠 |
| 6 | Plan the climb | Growth planning | 🟠 |
| 7 | Grow the customer | Customer growth | 🟠 |
| 8 | The strategy stack | Capstone: which model when + the board pitch | 🔴 |

## The running case

**Himalaya** - a fictional $40M ARR B2B2C SaaS platform whose growth has stalled. Every session diagnoses, decides, or designs for it; Session 8 delivers its board recommendation. Case bible: `materials/himalaya-case.md`.
