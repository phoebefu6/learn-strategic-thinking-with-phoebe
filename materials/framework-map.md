# Framework coverage map - learn-strategic-thinking-with-phoebe

The single source of truth for what each session teaches. ✓ = taught Live (45-min room),
◐ = Self-study depth on the page. Sources cited are the canonical origins - this course
teaches the working 80% of each framework; the original books/papers stay the deep end.

## Not covered by design (honest list)

- Financial modeling depth: DCF, M&A valuation, cap tables
- Org design frameworks (McKinsey 7S gets one cheat-sheet row in S8, not a session)
- Negotiation frameworks (BATNA et al.) - different course
- Statistical/experimental methods (A/B testing math) - covered in Phoebe's data courses
- Certification of any kind - this is a practitioner course, sources cited per session
